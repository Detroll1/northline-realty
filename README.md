# Northline Realty

Концепт лендинга агентства недвижимости: не реальное бюро, не клиентский сайт.

В браузере работают: фильтры по бюджету/району, избранное (localStorage), карточки объектов, валидация формы.
Заявки никуда не отправляются.

Стек: HTML, CSS, vanilla JS, Tailwind через CDN.

Live: https://detroll1.github.io/northline-realty/
