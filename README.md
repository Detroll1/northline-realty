# Northline Realty — премиальная недвижимость

> Independent web project — работающий продукт с реальной логикой, без фреймворков.

Брендовый лендинг бутик-агентства недвижимости Москвы: живой каталог с фильтрами (бюджет, район, площадь), избранное на localStorage, модальные карточки объектов, формы заявок с валидацией, параллакс и плавные анимации.

## Демо
🔗 **[Открыть на GitHub Pages](https://Detroll1.github.io/northline-realty/)**

![Скриншот](assets/screens/northline-realty.png)

## Стек
HTML / CSS / vanilla JS · Tailwind CDN · localStorage

## Запуск локально
Статический сайт — просто открой `index.html` или подними локальный сервер:
```bash
python -m http.server 8124
# → http://127.0.0.1:8124
```

## Структура
Один входной `index.html`, стили и скрипты рядом. Данные и логика — в JS без завусеженности от бэкенда: сайт полностью работает из коробки.
